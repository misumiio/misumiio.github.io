USTC相关资料与工具

发表于 2026-07-12 更新于 2026-08-12

算起来也是将近要有一年半的时间没有发博客了。可能是因为事情比较繁忙，或者是也没有什么东西好发的。到最近这段时间，有东西想要发了，然而旧的电脑长期关机懒得掏出来，博客的源代码在旧的电脑上，于是鸽了很久没发。现在掏出来要拿它当做MC的服务器了，于是顺便把博客的目录迁移到新电脑上。

受益于学校发的免费大模型api token, 很多事情都可以自动操作了。于是我制作了很多资料，还编写了项目。

这篇blog主要介绍一下USTC大一需要用到的一些我自制的资料。

历年转专业数据可视化

USTC 转专业比较自由不过还是需要竞争，不然的话就去个性化。

这个项目显示了除了管理学院以外的各学院，申请转入的人数以及拟接收人数、比例等数据的可视化，供转专业时候决策参考。

项目位置：https://github.com/misumiio/USTC_Change_Major_data
访问网页：https://misumiio.github.io/USTC_Change_Major_data/

《中国近现代史纲要》机考题库提纲

USTC《中国近现代史纲要》课程有上机考试，很多道选择题都需要背诵。为了能够在刷题之前先对内容有一个纵览，以及更好的复习，我用AI将这题库中的七百多道题目制作成一个复习资料，包含了七百多道题目的所有考点，并且不考的内容都没写进去。所以这是一个USTC专属的史纲复习资料。

项目位置：https://github.com/misumiio/USTC_History_Computer_Test

《大学物理 II》课程板书数字化整理及资料

《大学物理》系列课程是中科大开给管院同学的通识类物理课程，难度低于《力学》《热学》《电磁学》《光学》《原子物理》系列课程。涂涛老师的《大学物理 II》风评超好，为了期末复习我们将板书数字化了。

感谢ALXR提供的板书截图、Daniel用AI将其数字化。

项目位置：https://github.com/misumiio/USTC_university_phisics_II_Tu-Tao_blackboard

可以查看all.pdf。

USTC LLM API 校外访问

USTC为学生提供了每日100元（实测使用Deepseek v4 pro按照较高的缓存命中率一天大概能使用2亿token）的LLM api调用服务，包括deepseek v4 pro、qwen3.6、glm-5.2等模型。但是这个模型服务仅限校内访问，网络通的微批嗯服务仅向教师开放，网络信息中心刚购买的新的VPN服务不支持linux。而学校提供的vlab虚拟机可以在学校教育网以外的环境访问。因此我在vlab上面部署服务，使用vlab作为跳板机转发，使得暑假放假回家的同学也有机会使用学校提供的LLM服务，召唤AI干活。

项目位置：github.com/misumiio/apiproxy

如果你想使用我提供的服务，你可以先访问https://frp-six.com:50766/crt下载证书，然后安装到系统中，然后配置opencode使用这一个地址（无需修改原先的api key）

具体操作步骤可以查看项目中的README.md。
